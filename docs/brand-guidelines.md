# Portfolio Edition Brand Guidelines

## Identity

- Application: Grand Fina Property Management — Portfolio Edition
- Edition label: Portfolio Edition
- Demonstration property: Emerald Haven Residence
- Descriptor: A production-oriented property management portfolio project

Always state that operational and financial data are fictional. Do not describe this public edition as deployed, approved for live operations, family-operated, or tied to a real property's configuration.

## Voice

Use calm, precise, operational language. Separate confirmed records from pending work and distinguish fictional demonstration values from real-world claims.

## Visual system

- Deep green communicates structure and trust.
- Warm gold is a restrained accent for identity and focus.
- Off-white surfaces reduce glare while preserving contrast.
- Status colors must include text labels and never rely on color alone.

Use the existing coded logo mark and application favicon only. Screenshots must be captured from the fictional dataset and reviewed for metadata or local paths before publication.

Developer credit may use the name Sigit Syambudi. Personal email addresses must not appear in application content or documentation.
